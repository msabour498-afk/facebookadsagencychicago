# facebookadsagencychicago.com

Static lead-generation site for Facebook Ads Agency Chicago. Hosted on Cloudflare Pages.

## Editing

All pages are generated by `build.py`. Change the content or settings at the top of that file, then run:

```
python3 build.py
```

Commit the generated `.html` files along with your change. Styles live in `style.css`, menus, forms, tools and tracking in `site.js`.

## Cloudflare Pages settings

- Framework preset: None
- Build command: (none)
- Build output directory: `/`

## Forms

Forms submit directly to HubSpot (portal 247730807, form a71e4ae8-005c-4d3a-aea9-8f9e84267930, region na2). In HubSpot, the form should contain First name, Last name, Email, Phone, Company, Website URL and Message, with only Email required.

## Tracking

`dataLayer` events: `generate_lead`, `contact_click`, `tool_used`, `tool_to_offer_click`. Add a GTM container ID to `GTM_ID` in `build.py` to start sending them.
